# YML Авто

Личный форк [Yandex Music Lite](https://github.com/KorenskoyR/YandexMusicLite) (автор – KorenskoyR), адаптированный под режим сплита (навигатор + музыка) на головном устройстве Belgee X50, 1920×720.

## Отличия от оригинала

- **Режим «В авто» под сплит:** компоновка подстраивается под узкое окно, крупные кнопки и плитки без подписей, чтобы попадать не глядя.
- **Плейлисты прямо из режима «В авто»:** свои, понравившиеся и «Мне нравится».
- **Перемешивание** для любой очереди, кроме «Моей волны»; запоминается между запусками.
- **Синхронизированный текст песни** вместо обложки, включается сам, если текст есть.
- **Офлайн-волна:** следующие треки волны сохраняются в фоне в пределах лимита (0,5–4 ГБ). Без интернета играют они и скачанные треки, с появлением сети снова включается волна.
- **Скачивание плейлистов** для прослушивания без интернета.
- **Облегчённая графика** для слабого железа ГУ: без размытия, зернистости и фоновых анимаций.
- **Убрано:** FM-радио и «Хиты».
- **Отдельное приложение** («YML Авто»), ставится рядом с оригиналом; встроенное обновление берёт версии из этого репозитория.

## Установка

Скачать последний APK: [Releases](https://github.com/Ozo-bro/YML/releases/latest). Дальнейшие версии ставятся из приложения: «Настройки → Проверить обновления».

## Сборка

Каждый push собирает APK в GitHub Actions; push в `main` публикует релиз. Для подписи нужны секреты репозитория `KEYSTORE_BASE64` и `KEYSTORE_PASSWORD`.

Все права на товарные знаки и аудиоматериалы принадлежат их правообладателям.
